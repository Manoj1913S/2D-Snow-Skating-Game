# 2D-Snow-Skating-Game
This is a Simple 2D Snow skating  game which is made inside Unity


Snow Skating 2D
A simple 2D snow skating game made with Unity. This is my second game project where the player skates through snowy terrain, performs flips, collects power-ups, and tries to achieve the highest score possible.

Game Overview
In this game, the player controls a skater riding across a snowy environment.
The main objective is to travel as far as possible, perform flips in the air, collect power-ups, and earn a high score without crashing.

Features
Simple and fun 2D snow skating gameplay
Distance-based score system
Flip score system
Speed boost power-up
Crash and game over system
Restart game functionality
Particle effects
Skating particles
Crash particles
Finish/Game Over particles
Character selection system
Simple snowy environment
Score and UI system
